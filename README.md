# SAAD preprocessing code

This repository contains scripts used to preprocess, validate, and package the **SAAD** dataset  
(**S**timulus-driven **A**uditory **A**ttention **D**ichotic EEG dataset).

## Dataset

The dataset (raw EEG, preprocessed epochs, stimuli, and post-experiment ratings) is hosted on Zenodo:

https://doi.org/10.5281/zenodo.20287545

## Contents (planned)

- EEG preprocessing (filtering, ICA, epoching)
- Label and reaction-time extraction from benchmark logs
- Dataset layout validation and anonymization for release

## Citation

If you use this code or the SAAD dataset, please cite the Zenodo record and the accompanying Scientific Data manuscript (when available).
